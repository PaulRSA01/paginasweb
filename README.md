# Eco Pulse Costa Rica — Estudio Web

Landing page de ventas de Eco Pulse Costa Rica, un estudio freelance que hace sitios y motores de reserva directa para negocios turísticos.

Muestra los servicios (planes Esencial, Negocio y Pro), una galería de destinos y fauna de Costa Rica, el proceso de trabajo, precios de referencia y datos de contacto.

## Estructura

- `index.html` — página principal (sitio estático, sin build necesario).
- `plano.html` — copia idéntica de trabajo.

## Antes de publicar

Reemplazá los siguientes placeholders en `index.html`:

- `TU_NUMERO` en los enlaces de WhatsApp (`wa.me`)
- `tu@correo.com` en los enlaces `mailto`
- Los precios en USD son solo referencia — ajustalos a tu moneda y costos reales

## Deploy

Sitio 100% estático: se despliega en Vercel sin configuración adicional (detecta `index.html` en la raíz).
